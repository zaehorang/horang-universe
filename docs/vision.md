# Vision

## 한 문장

모르는 기술 개념을 **장소·인물·사건이 있는 세계**로 바꿔, 지도 위를 오가며 한 요청의 여정을 끝까지 따라가게 하는 학습 사이트.

## 왜 세계관인가

세계 하나(항구, 도서관)는 그 주제 안에서는 잘 설명하지만, 주제 사이의 관계는 보여 주지 못한다.
실제로 "주문 버튼 하나"는 DNS 와 TLS 를 지나, 로드밸런서와 WAF 를 통과해, Pod 에 닿고, 데이터베이스에서 행을 읽어 돌아온다.
세계를 지역으로 묶고 사이에 문을 두면, 따로 배운 지식이 **하나의 여정**으로 이어진다.

## 학습 흐름 (사이트에 들어온 사람)

1. **입구 둘** — 허브 지도를 둘러보며 들어간다. Phase 2 에서는 상단 검색칸에 개념을 치면 용어 사전에서 해당 세계·장면을 찾고 건물을 강조한다. 기본은 지도를 직접 눌러 자유롭게 오가는 것.
2. **지도에서 고르기** — 건물을 클릭하면 패널에서 개념 목록과 사건 목록, "들어가기"를 본다. hover 설명은 아직 구현하지 않았다.
3. **세계 안에서** — 사건을 고르고 자막을 따라간다. 궁금한 부품을 누르면 더 보기, 더 궁금하면 "실제로는?".
4. **문으로 넘어가기** — 공항의 "기록 금고(RDS)" 패널 아래 "이 금고 안은 데이터베이스 도서관에서" 버튼. 누르면 도서관의 해당 장면으로 간다. 등록부의 문 정보가 이 버튼을 만든다.
5. **돌아오기** — 세계 상단에 늘 허브로 가는 길과 현재 지역 이름.
6. **대륙 간 사건** (Phase 4) — 허브에서 "주문 버튼 하나"를 재생하면 점이 지역을 넘어 움직이고, 구간마다 그 세계의 장면으로 들어가는 링크.

## 제작 흐름 (모르는 개념에서 세계가 붙기까지)

1. 이 저장소에서 "X 가 어떻게 동작하는지 세계로 만들어 줘". 로컬 스킬 `universe` 가 발동.
2. **자리 찾기** — `worlds.json` 과 `shared/` 를 읽어 지역, 이웃 세계와의 문, 쓸 공용 인물·예시 값 벌을 정한다. 마땅한 지역이 없으면 새 지역을 제안.
3. **비유 설계** — 지역 분위기와 용어 사전의 기존 비유 계열에 맞춰 짓는다. (범용 스킬 몫)
4. **생성** — `worlds/<id>/` 에 content.js · world.js · world.css 와 얇은 index.html. 엔진 복사 없음.
5. **내용 작성** — 인물, 사건(유형 7종 `normal` `failure` `scale` `attack` `recovery` `revisit` `tour` 중 셋 이상이 목표. 셋 미만은 경고만 남긴다, D27), 3겹 설명, 실제로는?. 공용 값은 shared 상수.
6. **등록** — content.js `meta` 에 개념·문·손님 actor·예시 값 벌, `worlds.json` 에 지역·좌표·상태 `draft`.
7. **검사** — `check_world`(세계 내부) + `check_registry`(등록부·문·`meta.concepts` 배열 형식) + `build_atlas`(색인 재생성) + `check_all`(전체·생성물 동기). 개념 id 의 사전 대조는 Phase 2 에 연결한다.
8. **확인** — 로컬 서버로 허브에서 들어가 본다. 통과하면 `verified`.
9. **공개** — push → Actions 검사 → Pages. `draft` 는 공사 중으로만 보인다.

두 흐름은 **등록부와 세계 meta** 에서 만난다. 제작 쪽은 쓰고, 학습 쪽은 읽는다.

## 지역 (초기 셋)

| id | 표시 이름 | 들어갈 세계 |
|---|---|---|
| `network` | 네트워크 해안 | 우편 도시(http-https), 층층 우체국 빌딩(network-layers) |
| `ops` | 운영 항만 | 쿠버네티스 항구(k8s-harbor), EKS 보안 공항(eks-security) |
| `data` | 데이터 구역 | 데이터베이스 도서관(db-library) |

지역은 등록부에 추가하면 늘어난다. CS 기초(운영체제·프로세스·메모리)는 아직 지역이 없다.

## 하지 않는 것 (지금은)

진도·수료 시스템, 모바일 대응, 방문 통계, 다국어 콘텐츠.
